# 🚗 HỆ THỐNG QUẢN LÝ BÁN HÀNG SALON Ô TÔ

## 📌 Giới thiệu

Hệ thống quản lý bán hàng salon ô tô được xây dựng nhằm hỗ trợ quản lý thông tin xe, khách hàng, nhân viên và các hoạt động bán hàng trong salon ô tô.

Dự án giúp tối ưu quá trình quản lý dữ liệu, hỗ trợ thao tác bán hàng và nâng cao hiệu quả quản lý trong môi trường thực tế.

Đây là dự án được thực hiện nhằm rèn luyện kỹ năng lập trình Java, làm việc với cơ sở dữ liệu và xây dựng ứng dụng quản lý thực tế.

---

# ✨ Chức năng chính

## 👤 Quản lý tài khoản
- Đăng nhập hệ thống
- Phân quyền người dùng
- Quản lý thông tin tài khoản

## 🚘 Quản lý xe ô tô
- Thêm / sửa / xóa thông tin xe
- Tìm kiếm xe theo mã hoặc tên
- Quản lý giá bán và số lượng xe
- Cập nhật thông tin xe trong kho

## 👥 Quản lý khách hàng
- Lưu trữ thông tin khách hàng
- Tìm kiếm khách hàng
- Quản lý lịch sử mua hàng

## 🧾 Quản lý bán hàng
- Tạo hóa đơn bán xe
- Tính tổng tiền thanh toán
- Lưu lịch sử giao dịch
- Theo dõi đơn hàng

## 📊 Thống kê
- Thống kê doanh thu
- Theo dõi hoạt động bán hàng
- Quản lý dữ liệu hệ thống

---

# 🛠️ Công nghệ sử dụng

| Công nghệ | Mô tả |
|---|---|
| Java | Ngôn ngữ lập trình chính |
| Java Swing | Thiết kế giao diện desktop |
| MySQL | Quản lý cơ sở dữ liệu |
| XAMPP | Quản lý MySQL Server |
| Visual Studio Code | Môi trường phát triển |

---

# 🗄️ Cơ sở dữ liệu

Hệ thống sử dụng MySQL để lưu trữ dữ liệu:
- Thông tin xe ô tô
- Thông tin khách hàng
- Thông tin nhân viên
- Hóa đơn bán hàng
- Tài khoản đăng nhập
